歓送迎会の幹事は、普通の飲み会の幹事とは違います。

お店を押さえて人を集めれば終わり、ではありません。送られる人と迎えられる人がいて、その人たちをちゃんと立てる必要があります。挨拶の順番を間違えると気まずくなりますし、進行が止まると場の空気が落ちます。

しかも多くの場合、初めて任されます。前任者がいないまま「今年は君がやって」と言われて困るのが、この会の特徴です。

この記事では、進行の型と、挨拶の頼み方、そして場所の決め方をまとめました。**まず進行を決めてから場所を探す**のが、迷わない順番です。

## 🎓 歓送迎会が「普通の飲み会」より難しい理由

ただの飲み会なら、集まって飲めば成立します。歓送迎会はそうなりません。難しさは3つあります。

### 主役がいる

送られる人、迎えられる人がいます。**この人たちが「来てよかった」と思えたかどうかで、会の成否が決まります**。幹事が盛り上げても、主役が端で手持ち無沙汰にしていたら失敗です。

### 送る会と迎える会が、同時に進む

歓迎と送別を一度にやるのが歓送迎会です。新しく来た人は緊張していて、去る人は寂しさがある。**気持ちの向きが逆の人が、同じ部屋にいます**。順番を考えないと、どちらかが置いていかれます。

### 全員が主役と話せない

人数が増えるほど、主役と話せない人が出ます。「せっかく来たのに一言も話せなかった」が起きやすい会です。席の動かし方か、話す時間を作る工夫が必要になります。

## 📋 幹事が最初に決める5つのこと

場所を探す前に、この5つを決めます。ここが決まっていないと、場所を見ても判断できません。

### 1. 主役の都合

**何よりこれが先です**。送られる人の最終出社日、迎えられる人の着任日を確認して、その間で候補日を出します。主役が出られない日に設定してしまうのが、一番やってはいけない失敗です。

### 2. 人数と範囲

部署全員か、チーム単位か、関わりの深い人だけか。**人数が20人を超えるかどうかで、選べる場所が変わります**。10人以下なら選択肢がかなり広がります。

### 3. 会費

一人いくらにするか。主役の分を参加者で負担するのが一般的です。会社から補助が出るかどうかも、先に確認しておきます。

### 4. 開始と終了の時間

平日の夜なら18時半〜19時開始、2時間が標準です。**終わりの時間を先に決めておくと、進行が組めます。**

### 5. やるかやらないかを決めること

プレゼント、花束、寄せ書き、スライド上映、出し物。**全部やろうとすると時間が足りません**。2時間の会なら、多くても2つです。

## 🕐 当日の進行、時間の配分

2時間の会の型を書いておきます。これをベースに、人数や会場に合わせて伸縮させてください。

| 時間 | 内容 |
|---|---|
| 0:00 | 開会の挨拶（幹事）・乾杯の挨拶 |
| 0:05 | 乾杯、食事開始 |
| 0:30 | 歓迎される人の紹介・本人の挨拶 |
| 0:45 | 自由に歓談 |
| 1:15 | 送られる人へ、プレゼント贈呈・本人の挨拶 |
| 1:35 | 自由に歓談 |
| 1:50 | 締めの挨拶 |
| 2:00 | 解散 |

いくつか補足します。

**歓迎を先、送別を後にします**。送別の挨拶は会の山場になるので、後ろに置いた方が収まりがいいです。逆にすると、送別のあとに歓迎が来て、空気が中途半端になります。

**歓談の時間を2回に分けます**。一度にまとめると、主役と話せる人が限られます。間に区切りを入れると、席が動くきっかけになります。

**締めの挨拶は10分前に始めます**。押すのが前提の会なので、余裕を取っておきます。

3時間取れる場合は、歓談を2回とも30分ずつに伸ばすのがおすすめです。進行の項目を増やすよりも、話す時間を増やした方が満足度が上がります。

## 💬 挨拶を誰に、どの順番で頼むか

歓送迎会で一番気を遣うところです。**順番には型があります。**

### 開会の挨拶

幹事がやります。長くしません。「本日はお集まりいただきありがとうございます。ただいまから○○部の歓送迎会を始めます」で十分です。

### 乾杯の挨拶

**その場で一番役職が上の人**に頼みます。事前に「乾杯の挨拶をお願いできますか」と伝えておきます。当日に突然振るのは避けます。

### 歓迎される人の紹介

幹事が簡単に紹介してから、本人に一言もらいます。**事前に「挨拶をお願いします」と伝えておきます**。来たばかりで緊張しているので、不意打ちにしないことが大事です。

### 送られる人の挨拶

会の山場です。時間を十分に取ります。**最後まで待たせないこと**も気を配るポイントで、締めの直前ではなく、歓談を残した時間に置きます。挨拶のあとに話しに来る人がいるからです。

### 締めの挨拶

**役職が2番目の人**に頼むのが一般的です。乾杯と締めで同じ人にならないようにします。

---

いずれも、**前日までに本人へ伝えておきます**。当日に頼むと、内容を考える時間がありません。送られる人には「何分くらいで」と目安も伝えておくと、本人が組み立てやすくなります。

## 🎁 送る側・迎える側で用意するもの

やることを全部並べると多いので、優先順位をつけます。

### 送る人へ

- **プレゼント**：全員で出し合って1つ。金額は一人500〜1,000円を集める形が多いです
- **花束**：持ち帰りの負担があるので、電車通勤の方には小さめのものを
- **寄せ書き**：時間がかかるので、2週間前から回し始めます
- **写真や動画**：あると喜ばれますが、作る時間が必要です

**この4つのうち、2つまでに絞るのが現実的です**。全部やろうとして間に合わなくなるのが、よくある失敗です。

迷ったら、**プレゼントと寄せ書き**です。どちらも持ち帰って後から見られるものだからです。

### 迎える人へ

送別と違って、形のあるものは要りません。必要なのは**会のあとに名前と顔が一致している状態**です。

- 席を固定しない。歓談のときに動けるようにする
- 幹事が間に入って、一人ずつ紹介していく
- 名前と部署だけでも、全員と一度は話せるようにする

歓迎される側が一番困るのは、知らない人に囲まれて何を話せばいいか分からない状態です。幹事がつなぐだけで、だいぶ変わります。

## 📺 スライドや動画を流すなら、場所から考える

ここが場所選びの分かれ目になります。

寄せ書きの代わりにスライドを作る、思い出の写真をまとめて流す、送る人へのメッセージ動画を作る。こうした演出は喜ばれますが、**お店では流せないことが多いです。**

居酒屋の個室にモニターはありません。あっても小さく、音を出せません。プロジェクターを貸してくれる店もありますが、持ち込みの交渉が必要です。

そのため、**映像を使いたい会は、最初から場所を変えて考える**必要があります。

### 映像を流せる場所の候補

- **カラオケ**：モニターがあり、持ち込み接続ができる店もあります。ただし画面が小さく、人数が多いと見えません
- **レンタルスペース**：プロジェクターやスクリーンがある場所を選べます。音も出せます
- **貸し会議室**：設備は整っていますが、飲食が禁止のところが多いです

**映像をやるなら、一次会ではなく二次会に回す**という手もあります。一次会は店で普通にやって、二次会で部屋を借りてスライドを流す。この形なら、人数が減って落ち着いて見られます。

## 🏢 お店とレンタルスペース、どちらが向いているか

歓送迎会の目線で、違いだけ並べます。

| | お店 | レンタルスペース |
|---|---|---|
| 人数 | 20人以上も対応 | 10人前後まで |
| 料理 | 出てくる | 買い出しか出前 |
| 経費精算 | 領収書1枚 | 部屋代と飲食が別 |
| 映像を流す | 難しい | できる場所がある |
| 時間 | 2時間制が多い | 予約した分だけ |
| 席の移動 | しにくい | しやすい |

**人数が多い歓送迎会は、お店です**。20人でレンタルスペースは現実的ではありません。料理が出てくることと、領収書が1枚で済むことは、幹事にとって大きな利点です。

**レンタルスペースが向くのは、次の場合です。**

- 10人以下の、チーム単位の会
- スライドや動画を流したい会
- 一次会のあとの二次会
- 時間を気にせず話したい会

## 🙅 レンタルスペースが向いていない歓送迎会

正直に書いておきます。

- **人数が多い会**：定員10名前後の場所が多く、部署全体の歓送迎会には使えません
- **役職が上の方が多く出る会**：場所としての格が求められる席には合いません
- **料理をきちんと出したい会**：買い出しかデリバリーが基本です
- **大声で盛り上がる会**：住宅が近い建物では、騒音を控えるよう求められます
- **会社の経費で一括処理したい会**：部屋代と飲食代が別になるので、精算の手間が増えます
- **幹事が当日まで準備できない会**：買い出しの段取りが必要です

逆に、**少人数で、映像を使って、ちゃんと送りたい会**なら、お店より向いています。

## よくある質問

**Q. 歓送迎会は何時間取ればいいですか？**

A. 2時間が標準です。挨拶とプレゼント贈呈を入れると、歓談の時間は1時間ほどになります。スライド上映や出し物を入れるなら、3時間取った方が余裕があります。

**Q. 歓迎と送別、どちらを先にやりますか？**

A. 歓迎を先、送別を後です。送別の挨拶が会の山場になるので、後ろに置いた方が収まります。

**Q. 乾杯と締めの挨拶は、誰に頼めばいいですか？**

A. 乾杯は出席者の中で一番役職が上の方、締めは2番目の方に頼むのが一般的です。同じ人にならないようにします。どちらも前日までに伝えておきます。

**Q. 主役の会費はどうしますか？**

A. 参加者で負担するのが一般的です。会費を集めるときに、主役の分を人数で割って上乗せします。会社から補助が出る場合は、先に確認しておきます。

**Q. スライドを作る時間がないときはどうしますか？**

A. 写真を数枚、順番に表示するだけでも成立します。凝った編集は要りません。寄せ書きを撮影して大きく映すだけでも、全員で見られるという点で意味があります。

**Q. 二次会はやった方がいいですか？**

A. 主役の負担になるなら無理にやる必要はありません。ただ、一次会で話せなかった人が話せる場にはなります。参加は自由にして、人数が読めない前提で場所を押さえるのが現実的です。

## まとめ

歓送迎会の幹事で大事なのは、**場所より先に進行を決めること**です。

- 主役の都合を最優先で日程を決める
- 挨拶は前日までに頼んでおく
- 歓迎を先、送別を後
- やることは2つまでに絞る
- 映像を使うなら、場所から考える

この順番で決めていけば、場所は自然と絞れます。

幹事は目立たない仕事ですが、**会が終わったあとに主役が「ありがとう」と言いに来る瞬間**があります。そこまで設計できていれば、その会は成功です。
